# TeX64 FAQ

## What is TeX64?

TeX64 is a LaTeX editor for Windows and macOS, developed by Fermion Inc. It focuses on visual equation editing, on-device equation OCR and local TeX projects.

## Which platforms are supported?

Windows 10/11 x64 through Microsoft Store, and macOS 12 or later on Apple Silicon or Intel. Use the [official download page](https://tex64.com/download?ref=github). There is no Linux desktop release.

## What is free?

The core editor, visual equation input, OCR, local PDF builds and SyncTeX are free. Axiom is a separate online AI service. See the [current plans](https://tex64.com/#pricing).

## Does it work offline?

Local editing and OCR do. PDF builds also work locally once a suitable TeX distribution and the required packages are installed. Initial downloads, updates, account services and Axiom need internet access.

## Can it open my existing project?

TeX64 uses ordinary `.tex` files and folders. Preserve images, bibliography and style files, and use the required engine and packages. See the [migration guidance and published fixture](https://tex64.com/latex-editor#portability). Moving files does not reproduce a browser service's real-time coauthoring.

## Is OCR output guaranteed to be correct?

No. Check indices, symbols, fractions and matrix structure against the source image before using the result. The [OCR guide](https://tex64.com/math-ocr) explains the workflow and alternatives.

## Is the app source here?

No. This repository contains product information and feedback; application source remains private.

## Where can I get help?

Use [TeX64 Support](https://tex64.com/support) for problems, corrections and feature requests.
